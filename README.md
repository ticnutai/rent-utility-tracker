# Rent Meter Pro

יש לי שתי דירות שאני משכיר לשני דיירים שונים.
יש מונה חשמל ומונה מים: מונה ראשי, ומונה משנה באחת הדירות (דירה א').
בחשמל: מזינים קריאת מונה ראשי (קודמת ונוכחית) וקריאת מונה דירה א' (קודמת ונוכחית). המערכת תחשב את צריכת דירה א', ואת ההפרש עבור דירה ב'.
מזינים תעריף לקוט"ש, עם אפשרות למע"מ.
בנוסף יש תשלום קבוע של חיבור/בסיס שמתחלק חצי-חצי בין שתי הדירות.
במים: בדיוק אותו אופן חישוב לפי קוב מים (מונה ראשי, מונה דירה א', הפרש לדירה ב', תעריף לקוב, ודמי חיבור קבועים חצי-חצי).
גמישות בתקופות: אפשרות להגדיר כל טווח תאריכים (חודש, חודשיים, או טווח חופשי לבחירה).
תמיכה מלאה בהזנה רטרואקטיבית: אפשרות להזין תקופות היסטוריות מהעבר, לערוך ולשמור.
מעקב תשלומים: סימון סטטוס תשלום לכל דייר בכל תקופה (האם שילם, כמה, מתי והערות).
הפקת סיכום לשליחה: כפתור להעתקת פירוט מסודר לשליחה מהירה בוואטסאפ לכל אחד מהדיירים.
ממשק מלא בעברית (RTL), נוח וברור מאוד לשימוש מהנייד.
